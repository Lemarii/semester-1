# Repository Guidance

This repository contains COMP1850 course materials, exercises, worksheets, and example solutions organized by week and session.

## Working in this repository

- Read the nearby README or worksheet instructions before changing an exercise. Treat its required behavior, output formatting, allowed modules, and submission constraints as authoritative.
- Keep solutions appropriate for an introductory Python course and use concepts introduced by the relevant material. Avoid adding dependencies or advanced abstractions unless the task asks for them.
- Preserve starter-code scaffolding and unrelated student work. Make only the requested, local changes; do not fill in other exercises as part of a targeted task.
- Keep examples and solutions consistent with the surrounding files, including prompts and exact output where specified.
- For Python changes, run the affected script or the narrowest relevant check when practical. Some exercises require interactive input; use the documented examples and edge cases when validating them.
- Do not change assignment instructions or expected behavior unless explicitly requested.
